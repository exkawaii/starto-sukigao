# STARTO 好き顔セレクション

公開URL：**https://exkawaii.github.io/starto-sukigao/**

参考サイトの診断フローをベースにした、STARTO ENTERTAINMENT版のファン制作プロトタイプです。

## 含まれる機能

- STARTO公式「タレント」一覧に掲載されている全105名を最初から対象化
- 個人活動中のタレントと15グループ（20th Century / A.B.C-Z / Aぇ! group / Hey! Say! JUMP / King & Prince / Kis-My-Ft2 / NEWS / SUPER EIGHT / SixTONES / Snow Man / Travis Japan / WEST. / timelesz / なにわ男子 / ふぉ～ゆ～）を収録
- カテゴリは「好き顔9選」のみに整理
- イージー100回 / ガチモード200回の標準Eloレーティング式対戦
- 最終9人の境界が安定するまで自動で絞り込むモード（安全上限800回・60問後から手動終了可能）
- 対戦で選ばれたタレントを段階的に厳選し、最終9人だけを順位なしで表示
- 「好き顔9選」モードでグループを切り替えながら好きな9人を直接選択（選択順を保持）
- 公式アー写 / シンプル表示
- 2択・どっちも好き・わからない・ひとつ戻る（スキップはレーティングを動かさず、比較だけ進行）
- TOP 3と全体ランキング表示
- 公式プロフィールへのリンク
- Web Share API / URLコピー、結果画像のPNG保存
- レスポンシブ対応

### 自動「9人に絞る」モードの判定

自動モードは、勝者と敗者を同じK=32で対称更新する標準Eloを使います。「どっちも好き」は0.5対0.5の引き分けとして扱い、「わからない / スキップ」はランキングに影響させません。停止時には、全105名の登場確認に加えて、上位9人と9位・10位境界候補の比較回数、Eloスコアから計算したGlicko風の不確実幅、上位9人の3回連続一致を組み合わせます。

比較対象は、序盤は未登場メンバーを既登場メンバーにつなぎ、中盤以降は上位・9位境界・不確実幅が重なる候補を優先します。直近の人物とペア、登場回数の偏り、同一ペアの繰り返しにはペナルティを付けています。60問以上進めると「ここまでで終了」ボタンが使え、その時点のElo上位9人をすぐに結果表示できます。これは個人の好き嫌いというノイズを含む1人用の診断に合わせた実用的な停止判定で、統計的な正解を保証するものではありません。

## 起動

### いちばん簡単な方法

このフォルダ内の `index.html` をブラウザで開いてください。HTML / CSS / JavaScript の3ファイルが同じフォルダにあれば動作します。

### ローカルサーバーで起動する方法

- **Windows**：`start.bat` をダブルクリック
- **Mac**：`start.command` をダブルクリック（初回は右クリック → 開く）
- **Mac / Linux**：ターミナルで `start.sh` を実行

```bash
./start.sh
```

起動後、ブラウザで http://127.0.0.1:4173/ を開きます。

Python 3 がない場合は、https://www.python.org/downloads/ からインストールしてください。
